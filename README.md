# TCM Analytics — страница для руководства

Страница для руководства Tashkent City Mall, для телефона и компьютера. Устроена по концепции из гайда «Мобильная страница для руководства» и по макету команды («commerce app», обновление от 16.10.2026): облако объекта, один показатель за раз, сравнение до 4 объектов, график, топ брендов и комментарии. Все цифры берутся из Google-таблицы **«Реестр 26»**.

```
web/            страница (index.html — вёрстка и стили, app.js — логика, fonts.css — встроенные шрифты)
server/tcm/     сервер: чтение таблицы, расчёт набора данных, вход по паролю
server/tests/   тесты (на синтетических данных — реальные цифры в репозиторий не кладём)
```

Как это работает:

1. Сервер читает таблицу через сервисный аккаунт Google, только на чтение.
2. Переводит суммы в доллары.
3. Берёт трафик ТРЦ и зон из MallSense (счётчики Xovis), если заданы ключи `MALLSENSE_XTOKEN` и `MALLSENSE_APP_KEY`.
4. Отдаёт странице готовый JSON (`/api/data`).

Комментарии к объектам сервер хранит в `TCM_STATE_DIR/comments.json` (`/api/comments`).

Ключ сервисного аккаунта хранится только на сервере, в браузер он не попадает. Таблица перечитывается раз в 15 минут (`TCM_CACHE_MIN`). Если Google недоступен, страница показывает последние полученные данные и пишет об этом.

## Вид на телефоне и на компьютере

- **Телефон** (до 1024 px): одна колонка. Сверху облако объекта и выбор периода, ниже показатели, таблица, график и топ брендов.
- **Компьютер** (от 1024 px): шапка в одну строку. Слева облако, показатели, таблица и график. Справа топ брендов, он остаётся на экране при прокрутке. Поиск и фильтр открываются выпадающей панелью справа, «Сравнить с» — окном по центру. График растягивается на ширину колонки.

Вёрстка — в `web/index.html`: десктоп описан одним блоком `@media (min-width:1024px)`.

## Что умеет страница

- **Период и сравнение** выбираются в своём меню в цветах страницы (светлая и тёмная тема), а не в системном списке браузера.
- **Поиск** заменяет текущий выбор (бренд, категория, зона, ответственный, весь ТРЦ). **Фильтр** складывает параметры.
- **«Сравнить с»** — до 4 объектов (поиском, списками параметров или кнопкой «весь ТРЦ»). У каждой линии графика свой цвет. Для сопоставимости ТО, чеки и трафик при сравнении объектов показываются в среднем на бренд / на зону. Под таблицей — строки «Разница».
- **«Показать бренды»** у строки объекта раскрывает все бренды выборки с значениями. Нажатие на бренд здесь или в топе открывает этот бренд.
- **«i» у показателя** — что это, как считается, в чём измеряется. **«i» в облаке** — карточка объекта (у бренда: юрлицо, даты договора, ставка, % с ТО).
- **График**: при касании значения появляются прямо на графике и в строке под ним.
- **Комментарии** к объекту: «Комментарий ответственного» и «Комментарий руководства». Хранятся на сервере, видны всем пользователям. Комментарий руководства видят все, а пишут только пользователи с ролью «руководство»: это все, кроме логинов из `TCM_MANAGERS`. Сейчас `ceo` — руководство, `team` — команда (роль «ответственный»: комментарий руководства только читает).
- **Посещаемость ТРЦ сейчас** — на показателе «Трафик» для всего ТРЦ: вход сегодня (по последний полный час), вчера и с начала месяца к тем же дням прошлого года. Обновляется вместе с данными, раз в `TCM_CACHE_MIN` минут.
- **«Выгрузить анализ»** — пока заготовка: показывает подсказку. PDF по бренду появится, когда будет шаблон.
- Заставка держится, пока грузятся данные. Если страницу открыли во встроенном браузере Telegram/WhatsApp на iPhone, внизу появится подсказка открыть её в Safari. Ошибки самой страницы показываются красной полосой внизу (ошибки расширений браузера — нет).

## Откуда берутся данные

| На странице | Вкладка «Реестр 26» |
|---|---|
| Бренд, юрлицо, категория, подкатегория, под-подкатегория, сегмент, менеджер, площадь (зал + терраса), даты, ставка, % с ТО | **РЕЕСТР** |
| Этаж | РЕЕСТР: «Секция (TRAFFIC)», если пусто — номер помещения |
| Зона и её замер трафика | РЕЕСТР: «Секция (TRAFFIC)», например «L3 Main atrium (262 367 ppl)» |
| ТО и чеки по месяцам | **Тurnover** (первая буква кириллическая) |
| Курс сум → $ | **Курс**: курс ЦБ на конец месяца |
| Аренда, превышение ТО, OPEX + маркетинг | вкладка каждого бренда: строки «Аренда без НДС», «Превышение ТО», «OPEX+Marketing» |
| Трафик ТРЦ и зон | **MallSense API**: вход посетителей (`fpc_sum_pass_count_in_wh`) по месяцам, ТРЦ — объект 27283, зоны — 21 зона локации 558. Если MallSense недоступен — вкладка **Заполняемость Mall** и оценка зон |

**Выборка.** В неё входят действующие договоры: статусы «Актуальный», «Партнеры» (якорные арендаторы — Inditex, Galmart, Cinematica…), «На стадии открытия» и «Новый». Склады (категория Storage) и неактуальные договоры исключаются. Строка «Терраса» прибавляет площадь к своему бренду.

**Месяцы.** Данные помесячные. Последним считается месяц, за который ТО сдали не меньше 80 % брендов от предыдущего месяца, поэтому частично заполненный текущий месяц не искажает картину.

**Что сервер не смог сопоставить**, видно в `/api/data` → `quality`:
- `noTurnover` — бренды без строки в Тurnover;
- `noBrandTab` — бренды без своей вкладки.

## Показатели

Все деньги указаны в долларах и без НДС. Пересчёт идёт по курсу конца каждого месяца, поэтому прирост в долларах включает влияние курса.

| Показатель | Формула |
|---|---|
| Товарооборот | Σ ТО брендов выборки за период |
| ТО на м² | ТО ÷ площадь работающих брендов (средняя по месяцам периода) |
| Отдача площади | доля ТО выборки в ТО ТРЦ ÷ доля её площади в площади ТРЦ |
| Отдача на трафик | доля ТО выборки в ТО ТРЦ ÷ доля трафика её зон в трафике всех зон (средний месячный вход по MallSense; без него — замер из реестра) |
| OCR | (аренда + превышение ТО + OPEX и маркетинг) ÷ ТО, по брендам с ТО за месяц; рост — хуже |
| Чеки | Σ чеков |
| Средний чек | ТО ÷ чеки (только по брендам, сдавшим чеки) |
| Трафик зоны | вход по счётчикам MallSense: ТРЦ — вход в ТРЦ, выборка — сумма входов в её зоны (посетитель, прошедший несколько зон, учтён в каждой). Без MallSense — оценка: замер зоны из реестра × сезонность ТРЦ |
| Усл. конверсия | чеки ÷ трафик (по месяцам, где есть трафик) |

**Периоды:**
- последний месяц;
- предыдущий месяц;
- последние 3 месяца;
- с начала года;
- последние 12 месяцев;
- прошлый год;
- свой диапазон месяцев.

**Сравнение:** с предыдущим периодом той же длины, год к году или со своим периодом.

**Рейтинг брендов.** Бренд без данных за период (не открыт, не сдал отчёт) в рейтинге не участвует.

## Запуск на своём сервере

Полная пошаговая инструкция (в том числе для Claude на сервере): **`DEPLOY.md`**. Основной вариант — без домена, через **Tailscale** (`tailscale serve` — только в сети Tailscale, или `tailscale funnel` — публично, адрес `https://<сервер>.<tailnet>.ts.net`). Приложение слушает только `127.0.0.1:8000`. В `deploy/` лежат docker-compose (Caddy — опциональный профиль для своего домена) и unit-файл systemd. Проверить доступ к таблице без запуска сервера можно командой `python -m tcm.check`.

Ниже — вариант со своим доменом (кратко):

### 1. Доступ к таблице

Откройте «Реестр 26» на чтение для `client_email` из JSON-ключа: «Настройки доступа» → добавить адрес → «Читатель».

### 2. Пользователи

Для каждого пользователя получите хэш пароля:

```bash
cd server && pip install -r requirements.txt
python -m tcm.auth 'пароль-руководителя'
```

Пары «логин:хэш» перечислите через запятую в `TCM_USERS`.

### 3. Настройки

Скопируйте `.env.example` в `.env` и заполните. Нужен `TCM_SECRET` — случайная строка не короче 32 символов.

### 4. Docker

```bash
docker build -t tcm-analytics .
docker run -d --name tcm --restart unless-stopped \
  --env-file .env \
  -v /secure/path/sa.json:/secrets/sa.json:ro \
  -p 127.0.0.1:8000:8000 tcm-analytics
```

### 5. HTTPS

Поставьте перед контейнером nginx или Caddy с HTTPS и проксируйте на `127.0.0.1:8000`. Без HTTPS cookie входа не работает (`TCM_COOKIE_SECURE=1`). Если прокси на другом адресе, укажите его IP в `FORWARDED_ALLOW_IPS`, чтобы ограничение попыток входа видело настоящий адрес клиента.

### Публикация по пути (не в корне домена)

Если страница живёт по префиксу (например, `/ceo` за `tailscale funnel --set-path /ceo`), задайте `TCM_BASE_PATH=/ceo`. Tailscale срезает префикс, поэтому сервер сам добавляет его в редиректы, в `<base href>` страницы и в путь cookie.

### Локальная проверка без Docker

```bash
cd server
pip install -r requirements-dev.txt
python -m pytest
export TCM_SHEET_ID=... TCM_SA_KEY_FILE=/path/sa.json TCM_USERS='ceo:scrypt.…' \
       TCM_SECRET=$(python -c "import secrets;print(secrets.token_hex(32))") TCM_COOKIE_SECURE=0
uvicorn --factory tcm.app:create_app --port 8000
```

## Безопасность

- Ключ сервисного аккаунта и `.env` в git не коммитятся (`.gitignore`). Если ключ где-то засветился, выпустите новый в Google Cloud Console и удалите старый.
- Пароли хранятся только в виде хэша scrypt.
- После 5 неудачных попыток входа с одного адреса вход блокируется на 15 минут.
- Сессия живёт 14 дней, cookie `HttpOnly` и `SameSite=Lax`.

## Открытые вопросы

1. **Трафик по зонам** теперь из MallSense. Зона B1 Metro corridor в реестре не встречается, поэтому на страницу не попадает.
2. **«Отдача на трафик»** считается по доле замера зон. Формулу нужно подтвердить.
3. **Трафик ТРЦ** берётся из MallSense; вкладка «Заполняемость Mall» нужна только как запасной вариант.
4. **Курс.** Сейчас берётся курс ЦБ на конец месяца, как в карточках брендов. Если нужен другой (средний за месяц), это одна строка в `server/tcm/model.py` (`parse_fx`).
5. **Шрифты.** Пока подключены временные аналоги — Cormorant Garamond и Montserrat (файлами в `web/fonts.css`, без Google Fonts). Kudryashev Display и Cera Pro нужно подключить файлами.
6. **Отличия от макета команды.** Данные в таблице помесячные, поэтому периоды «Сегодня», «Вчера», «Неделя» и сравнения «Те же дни недели / числа месяца» не показываются: вместо них — месяцы, кварталы, полугодие, год. «Выгрузить анализ» — заготовка, как и в макете.
