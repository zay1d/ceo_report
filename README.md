# TCM Analytics — мобильная страница для руководства

Страница для руководства Tashkent City Mall. Устроена по концепции из гайда «Мобильная страница для руководства»: облако объекта, один показатель за раз, сравнение, график и топ брендов. Все цифры берутся из Google-таблицы **«Реестр 26»**.

```
web/            страница (index.html — вёрстка и стили, app.js — логика)
server/tcm/     сервер: чтение таблицы, расчёт набора данных, вход по паролю
server/tests/   тесты (на синтетических данных — реальные цифры в репозиторий не кладём)
```

Как это работает:

1. Сервер читает таблицу через сервисный аккаунт Google, только на чтение.
2. Переводит суммы в доллары.
3. Отдаёт странице готовый JSON (`/api/data`).

Ключ сервисного аккаунта хранится только на сервере, в браузер он не попадает. Таблица перечитывается раз в 15 минут (`TCM_CACHE_MIN`). Если Google недоступен, страница показывает последние полученные данные и пишет об этом.

## Откуда берутся данные

| На странице | Вкладка «Реестр 26» |
|---|---|
| Бренд, юрлицо, категория, подкатегория, под-подкатегория, сегмент, менеджер, площадь (зал + терраса), даты, ставка, % с ТО | **РЕЕСТР** |
| Этаж | РЕЕСТР: «Секция (TRAFFIC)», если пусто — номер помещения |
| Зона и её замер трафика | РЕЕСТР: «Секция (TRAFFIC)», например «L3 Main atrium (262 367 ppl)» |
| ТО и чеки по месяцам | **Тurnover** (первая буква кириллическая) |
| Курс сум → $ | **Курс**: курс ЦБ на конец месяца |
| Аренда, превышение ТО, OPEX + маркетинг | вкладка каждого бренда: строки «Аренда без НДС», «Превышение ТО», «OPEX+Marketing» |
| Трафик ТРЦ | **Заполняемость Mall** |

**Выборка.** В неё входят действующие договоры: статусы «Актуальный», «Партнеры» (якорные арендаторы — Inditex, Galmart, Cinematica…), «На стадии открытия» и «Новый». Склады (категория Storage) и неактуальные договоры исключаются. Строка «Терраса» прибавляет площадь к своему бренду.

**Месяцы.** Данные помесячные. Последним считается месяц, за который ТО сдали не меньше 80 % брендов от предыдущего месяца, поэтому частично заполненный текущий месяц не искажает картину.

**Что сервер не смог сопоставить**, видно в `/api/data` → `quality`:
- `noTurnover` — бренды без строки в Тurnover;
- `noBrandTab` — бренды без своей вкладки.

## Показатели

Все деньги указаны в долларах и без НДС. Пересчёт идёт по курсу конца каждого месяца, поэтому прирост в долларах включает влияние курса.

| Показатель | Формула |
|---|---|
| Товарооборот | Σ ТО брендов выборки за период |
| ТО на м² | ТО ÷ площадь работающих брендов (средняя по месяцам периода) |
| Отдача площади | доля ТО выборки в ТО ТРЦ ÷ доля её площади в площади ТРЦ |
| Отдача на трафик | доля ТО выборки в ТО ТРЦ ÷ доля замера трафика её зон в сумме замеров всех зон |
| OCR | (аренда + превышение ТО + OPEX и маркетинг) ÷ ТО, по брендам с ТО за месяц; рост — хуже |
| Чеки | Σ чеков |
| Средний чек | ТО ÷ чеки (только по брендам, сдавшим чеки) |
| Трафик зоны | ТРЦ — по счётчикам. Зоны — **оценка**: замер зоны из реестра × сезонность трафика ТРЦ |
| Усл. конверсия | чеки ÷ трафик (по месяцам, где есть трафик) |

**Периоды:**
- последний месяц;
- предыдущий месяц;
- последние 3 месяца;
- с начала года;
- последние 12 месяцев;
- прошлый год;
- свой диапазон месяцев.

**Сравнение:** с предыдущим периодом той же длины, год к году или со своим периодом.

**Рейтинг брендов.** Бренд без данных за период (не открыт, не сдал отчёт) в рейтинге не участвует.

## Запуск на своём сервере

Полная пошаговая инструкция (в том числе для Claude на сервере): **`DEPLOY.md`**. В `deploy/` лежат docker-compose с Caddy (HTTPS) и unit-файл systemd. Проверить доступ к таблице без запуска сервера можно командой `python -m tcm.check`.

Коротко:

### 1. Доступ к таблице

Откройте «Реестр 26» на чтение для `client_email` из JSON-ключа: «Настройки доступа» → добавить адрес → «Читатель».

### 2. Пользователи

Для каждого пользователя получите хэш пароля:

```bash
cd server && pip install -r requirements.txt
python -m tcm.auth 'пароль-руководителя'
```

Пары «логин:хэш» перечислите через запятую в `TCM_USERS`.

### 3. Настройки

Скопируйте `.env.example` в `.env` и заполните. Нужен `TCM_SECRET` — случайная строка не короче 32 символов.

### 4. Docker

```bash
docker build -t tcm-analytics .
docker run -d --name tcm --restart unless-stopped \
  --env-file .env \
  -v /secure/path/sa.json:/secrets/sa.json:ro \
  -p 127.0.0.1:8000:8000 tcm-analytics
```

### 5. HTTPS

Поставьте перед контейнером nginx или Caddy с HTTPS и проксируйте на `127.0.0.1:8000`. Без HTTPS cookie входа не работает (`TCM_COOKIE_SECURE=1`). Если прокси на другом адресе, укажите его IP в `FORWARDED_ALLOW_IPS`, чтобы ограничение попыток входа видело настоящий адрес клиента.

### Локальная проверка без Docker

```bash
cd server
pip install -r requirements-dev.txt
python -m pytest
export TCM_SHEET_ID=... TCM_SA_KEY_FILE=/path/sa.json TCM_USERS='ceo:scrypt.…' \
       TCM_SECRET=$(python -c "import secrets;print(secrets.token_hex(32))") TCM_COOKIE_SECURE=0
uvicorn --factory tcm.app:create_app --port 8000
```

## Безопасность

- Ключ сервисного аккаунта и `.env` в git не коммитятся (`.gitignore`). Если ключ где-то засветился, выпустите новый в Google Cloud Console и удалите старый.
- Пароли хранятся только в виде хэша scrypt.
- После 5 неудачных попыток входа с одного адреса вход блокируется на 15 минут.
- Сессия живёт 14 дней, cookie `HttpOnly` и `SameSite=Lax`.

## Открытые вопросы

1. **Трафик по зонам.** В таблице есть только один замер на зону, помесячной динамики по зонам нет. Если появятся данные счётчиков по зонам (Basic report), «Трафик зоны» и «Конверсия» станут точными.
2. **«Отдача на трафик»** считается по доле замера зон. Формулу нужно подтвердить.
3. **Трафик ТРЦ** в «Заполняемость Mall» заполнен по июнь 2026. За следующие месяцы трафик и конверсия показываются с пометкой о пропуске.
4. **Курс.** Сейчас берётся курс ЦБ на конец месяца, как в карточках брендов. Если нужен другой (средний за месяц), это одна строка в `server/tcm/model.py` (`parse_fx`).
5. **Шрифты.** Пока подключены временные аналоги — Cormorant Garamond и Montserrat. Kudryashev Display и Cera Pro нужно подключить файлами.
